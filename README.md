# 🍳 NaFome

Plataforma web focada em descoberta rápida de receitas simples, baratas e práticas utilizando ingredientes comuns do dia a dia.  
O objetivo do projeto é ajudar pessoas a decidirem rapidamente o que cozinhar com o que já possuem em casa.

O NaFome prioriza:
- simplicidade
- rapidez
- acessibilidade
- receitas econômicas
- experiência mobile leve

---

## Stack

| Camada | Tecnologia |
|---|---|
| Frontend | HTML5 |
| Estilização | CSS3 |
| Lógica | JavaScript Vanilla |
| Dados | JSON |
| Hospedagem | Netlify |
| Versionamento | Git + GitHub |
