Soda Italiana de Frutas do Brasil

Soda italiana com jeitinho brasileiro, para você se sentir na praia sem sair do sofá.

⏱ 8 min 📊 Fácil 💰 R$ 9,00 👤 2 porções

🛒 Ingredientes

  • 100ml de polpa de maracujá
  • 100ml de polpa de manga
  • água com gás
  • gelo
  • folhas de hortelã para decorar

👨‍🍳 Modo de Preparo

  1. Misture as polpas como se estivesse criando uma obra de arte tropical.
  2. Adicione bastante gelo porque calor é inimigo do bom humor.
  3. Complete com água com gás para aquele toque fashion italiano.
  4. Decore com hortelã para fingir que é chique — funciona.
💡 Dica: Use polpas naturais para não pagar mico com sabor artificial.
